# Images Directory

Place your image files in the following folders:

## /assets/images/products/
Product images. Recommended: 800×1067px (3:4 ratio), JPG or WebP.
Name them: `p1.jpg`, `p2.jpg` ... or by slug e.g. `cashmere-coat-1.jpg`

## /assets/images/banners/
Hero and section banner images. Recommended: 1920×1080px minimum.

Required banner images referenced in the frontend:
- `hero.jpg`       — Homepage hero background
- `promo.jpg`      — Promo/sale banner background
- `auth.jpg`       — Login / Register page side panel
- `about1.jpg`     — About page
- `cat-women.jpg`  — Women's category
- `cat-men.jpg`    — Men's category
- `cat-acc.jpg`    — Accessories category
- `cat-home.jpg`   — Home & Living category

## /assets/images/
- `favicon.svg`    — Already created ✓
- `placeholder.jpg`— Fallback product image (create a simple grey square)

## Tips
- Use WebP format for best performance
- Compress all images before uploading (use squoosh.app or similar)
- Keep product images consistent in size and background colour
